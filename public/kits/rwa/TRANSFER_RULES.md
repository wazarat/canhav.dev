# Transfer rules worksheet

Who may hold a token with restrictions, the check behind it, and the powers the issuer keeps, written before any token is issued.

| Decision | What to write | Value |
|----------|---------------|-------|
| Jurisdictions | Where holders may be and where they may not. | |
| Investor class | Retail, accredited, institutional, and the proof of each. | |
| Identity check | The registry or the attestation that proves eligibility and who issues it. | |
| List maintainer | Who adds and removes wallets and with what delay. | |
| Freeze | When a wallet may be frozen, by whom and how it is lifted. | |
| Forced transfer | When the issuer may move a balance and the record it leaves. | |
| Recall | When the issuer may recall tokens and what the holder receives. | |
| Exit rights | The redemption or sale a holder keeps no matter what, and the test that proves it. | |
| Disclosure | The screen that shows these rules before a purchase. | |

Fill the Value column before the first contract is written. A row left
blank is undecided and should say what would decide it.
