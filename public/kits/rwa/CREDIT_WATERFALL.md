# Credit waterfall worksheet

Tranches, first loss and the order money flows in a credit pool, written before the first loan.

| Decision | What to write | Value |
|----------|---------------|-------|
| Tranches | Senior, junior and first loss with the share and the rate of each. | |
| First loss | Who provides it, its size and whether it is the team's own token. | |
| Repayment order | How interest and principal flow through the tranches. | |
| Loss order | How a loss hits first loss, junior and senior. | |
| Default | What a missed payment triggers and when a loan is in default. | |
| Recovery | Who pursues it, the cost and how a recovery flows back. | |
| Reporting | What lenders receive, how often and where. | |
| Withdrawals | The queue and its cadence, and what a lender sees while waiting. | |

Fill the Value column before the first contract is written. A row left
blank is undecided and should say what would decide it.
