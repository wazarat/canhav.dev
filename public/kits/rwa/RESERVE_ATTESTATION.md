# Reserve attestation worksheet

The reserve behind a backed token, who checks it and what a missing check stops.

| Decision | What to write | Value |
|----------|---------------|-------|
| Reserve | What backs the token, one to one or over. | |
| Custodian | Who holds it and under what agreement. | |
| Attester | Who checks the reserve and how independent they are. | |
| Cadence | How often the attestation is produced and published. | |
| On-chain path | The feed or the signed report that minting reads. | |
| Stale rule | How old an attestation may be before minting stops. | |
| Shortfall | What happens when the reserve is below supply. | |
| Publication | Where holders read the latest attestation. | |

Fill the Value column before the first contract is written. A row left
blank is undecided and should say what would decide it.
