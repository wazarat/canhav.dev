# Slashing disclosure worksheet

What can be slashed, by whom, with what evidence and who takes the loss, written for the deposit screen.

| Decision | What to write | Value |
|----------|---------------|-------|
| Faults | Each fault that is slashed, in plain words. | |
| Evidence | What proves a fault and who may submit it. | |
| Amount | The amount slashed per fault, as a share or a number. | |
| Absorption | Pro rata across holders, an insurance buffer first, or the operator's bond first. | |
| Buffer | If a buffer exists, its size, its funding and when it is used up. | |
| Operator bond | For a service, the bond per operator and its share of total security. | |
| Disclosure | The screen that shows this before a deposit or a registration. | |
| History | Where past slashes are recorded and shown. | |

Fill the Value column before the first contract is written. A row left
blank is undecided and should say what would decide it.
