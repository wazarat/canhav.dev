# Governance parameters worksheet

Every number and every role in a token governance stack, with the reason behind each.

| Decision | What to write | Value |
|----------|---------------|-------|
| Voting token | The token that votes and whether it carries checkpoints or is wrapped. | |
| Counting | Balances, delegations or both, and the snapshot block. | |
| Proposal threshold | The share of supply needed to propose and why that number. | |
| Voting delay | Time between a proposal and the vote opening. | |
| Voting period | How long a vote runs. | |
| Quorum | The share of supply that must vote and why that number. | |
| Timelock | The delay between a passed vote and execution, and who may cancel. | |
| Treasury inflows | Every source that pays in, such as creator fees from a launched token. | |
| Kept roles | Each power the multisig keeps, its signers, its limit and its sunset. | |
| Emergency | The pause and the veto, who holds them and when they expire. | |
| Disclosure | Where a holder reads all of the above before delegating or voting. | |

Fill the Value column before the first contract is written. A row left
blank is undecided and should say what would decide it.
