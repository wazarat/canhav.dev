# Claims path worksheet

Each step from a filed claim to money moving, and what happens when the pool is short.

| Decision | What to write | Value |
|----------|---------------|-------|
| Filing | Who may file, what they submit and the fee or bond they post. | |
| Decider | Who decides, a bonded assertion, a vote, a court or an assessor. | |
| Window | How long anyone may dispute before a claim is final. | |
| Escalation | Where a disputed claim goes and who pays for it. | |
| Outcome | What happens to the bond on each outcome. | |
| Payout | The contract path that moves money once a claim is decided. | |
| Shortfall order | Which tranche absorbs a loss first, and then which. | |
| Shortfall rule | Pro rata, queued or capped when claims exceed the pool. | |
| Record | Where past claims and their outcomes are published. | |

Fill the Value column before the first contract is written. A row left
blank is undecided and should say what would decide it.
