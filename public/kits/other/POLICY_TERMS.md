# Policy terms worksheet

What a cover pool promises, written before the first policy is sold.

| Decision | What to write | Value |
|----------|---------------|-------|
| Covered event | The event that triggers a payout, in words a buyer understands. | |
| Proof | What proves the event happened, a feed, an assertion or an assessment. | |
| Exclusions | What is not covered even when the event happens. | |
| Term | How long a policy runs and whether it renews. | |
| Premium rule | How the premium is set, who may change it and the delay. | |
| Payout formula | How a payout is computed from the loss or the reading. | |
| Limit | The most one policy pays and the most one event takes from the pool. | |
| Shortfall | What a buyer is paid when claims exceed the pool. | |
| Disclosure | Where a buyer reads all of the above before paying. | |

Fill the Value column before the first contract is written. A row left
blank is undecided and should say what would decide it.
